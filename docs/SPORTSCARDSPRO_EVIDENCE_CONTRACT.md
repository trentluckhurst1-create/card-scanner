# SportsCardsPro Evidence Contract

SportsCardsPro is a **market-evidence research source**, not an active acquisition retailer in Card Scanner.

## Public Card Scanner behavior

- Exact-card comparison remains between active retailer listings.
- For serial-numbered cards, individual copy numbers within the same print run are comparable (for example 1/10 vs 8/10). Different print runs are different variants.
- Each exact comparison may link the user to a SportsCardsPro search for the same card identity.
- Card Scanner does not scrape, cache, persist, export, or republish SportsCardsPro proprietary price/history data in the public application without express permission.
- SportsCardsPro data cannot create a Card Scanner BUY or STRONG BUY signal by itself.

## Future authorized integration

If an eligible SportsCardsPro subscription/API token and redistribution permission are obtained, integrate through the documented API/CSV service. Keep the token secret. Current documented API/CSV price endpoints provide current condition values; historic sales are not available through those API/CSV endpoints, so any future historic-sales integration must use a separately authorized mechanism.
